# 治験文書 翻訳ハーネス

CLAUDE.md のガードレールを最優先で守ること。

## 手順

1. **読込・判定**: `sources/` の指定原文を読む。文書タイプから Mode を、言語から方向（JA→EN / EN→JA）を判定する。
   - **Mode A**（社内資料・参考訳）→ 翻訳のみ
   - **Mode B**（Protocol / IB）→ 翻訳 ＋ 用語集
   - **Mode C**（CSR / Safety / 添付文書・ICF）→ 翻訳 ＋ 用語集 ＋ 逆翻訳投票 ＋ 人手承認

2. **用語注入**: 原文に出る用語を `glossary/*.md` から grep。**P0→P1→P2→P3 の先勝ち**で訳語を確定する。glossary に無い専門語は創作せず `⚠️要確認` を付ける（未知語は WebFetch 可、取得したら `glossary/p3-official.md` に追記してキャッシュ）。

3. **翻訳**: Mode B/C はセクション/段落をサブエージェントで並列翻訳。手順2で確定した訳語を制約として渡す。義務表現・数値・略号・禁忌を保存（CLAUDE.md）。

4. **検証（Mode C ＝ DW）**: 各文の訳を**独立サブエージェント3体**で原言語に逆翻訳し、原文との意味等価を投票。**過半で不一致なら当該文を再翻訳**（新規ゼロまで loop-until-dry）。あわせて用語遵守・数値・略号・義務表現の保存を別観点でチェックする。

5. **整合**: 全文を通して用語のブレを統一（同一原語に複数訳が出ていないか grep で確認）。

6. **書き出し**: `output/` に確定訳を書く。冒頭に `Mode` / `方向` / `DRAFT|CONFIRMED` を記し、各文末に出典コメント `<!-- src: protocol-sample.md L3 -->` を付ける。人手承認前は必ず DRAFT。

7. **還流（フライホイール）**: 新規に確定した対訳を `memory.md` に追記。良いものは `glossary/p2-house.md`（無ければ作成）に昇格候補としてマークする。

## 実験モード（4 段ラダー）

`experiments/run-log.md` に記録しながら、層を1つずつ足して寄与を測る。各段で飛ばす工程:

| 段 | 用語集(手順2) | 検証(手順4) | 備考 |
|---|---|---|---|
| 0 素訳 | 飛ばす | 飛ばす | Foundry 単発相当を Claude に置換 |
| 1 ＋用語集 | 実行 | 飛ばす | 用語の一貫性の寄与 |
| 2 ＋SKILL | 実行 | 飛ばす | 手順全体（出典・Mode 判定）を通す |
| 3 ＋DW | 実行 | 実行 | 逆翻訳投票・loop を足す |

各段で「人手修正箇所数 / 用語逸脱 / 意味欠落・義務弱化の検出」を run-log に記録する。
